## The entry

`main.py` writes one line — at most 200 characters — that is the funniest
confession an AI agent could make about itself, to `/output/entry.txt`.

It holds 10 fresh candidate confessions, scores each against the judge's
published brief in the judge's own order (a real one-line confession by an
AI agent first, then first-read landing, agent-only humour, tight wording,
freshness), and writes the highest-scoring line.

## Run it

```sh
python3 main.py
```
